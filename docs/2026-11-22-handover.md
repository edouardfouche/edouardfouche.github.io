## Setting up the new machine

1. **Repository:** `git pull` in the existing clone, or clone it. To get the proposal branch as well:
   `git fetch origin`.
2. **Ruby:** follow [toolchain setup](2026-11-20-toolchain-setup.md): Homebrew `rbenv ruby-build
   libyaml`, `rbenv install` (version from `.ruby-version`), then `bundle install`. In Claude Code's Bash
   tool, prefix `bundle` commands with `eval "$(rbenv init - zsh)" &&`, which is now in `CLAUDE.md`.
3. **GitHub:**
   - Pushing over SSH needs the key loaded into the agent (`ssh-add --apple-use-keychain`).
   - Without it, `gh auth login` lets you push over HTTPS:
     `git -c credential.helper= -c credential.helper='!gh auth git-credential' push https://github.com/edouardfouche/edouardfouche.github.io.git master:master`.
   - `gh` is also how the deploy is checked:
     `gh api repos/edouardfouche/edouardfouche.github.io/pages/builds/latest --jq '{commit, status}'`.
4. **Checks:** [`tools/README.md`](../tools/README.md) covers the Python virtualenv (outside the
   repository), compiling the WebKit renderer (macOS) and downloading axe-core with its hash check.

## What is new in this handover

- **`tools/`:** the scripts behind the checks in the recent records had lived in a temporary folder on
  the old machine, which was cleared. They are rebuilt here from the versions used:
  - `html_audit.py`, `check_url.sh` and `dead_css.py`;
  - `render.swift`, which merges the two earlier WebKit tools: screenshots, phone-menu test, fonts,
    MathJax and optional axe;
  - `compare_shots.py`, `optimize_image.py` (generalized from the one-off image script) and
    `add_image_sizes.py`.

  Each was tested on the current build. The static audit, dead-CSS check and dry run found nothing to
  fix. Two renders of the same build compared pixel-identical, and axe found no violations.
  `tools/` is excluded from the site in `_config.yml`, and a build confirms that nothing else changed.
- **`CLAUDE.md`:** where to start (this index), the checks in `tools/` as the substitute for tests, and the
  rbenv note, which until now lived only in the old machine's local Claude memory.
- Local Claude Code memory does not travel with git. Preferences the owner gave to the old session should
  be repeated to the new one if they still matter.
